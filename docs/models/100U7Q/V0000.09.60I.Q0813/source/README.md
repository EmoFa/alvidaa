# 100U7Q source notes (sanitized)

These are the author's research notes for the 100U7Q / `V0000.09.60I.Q0813`
chain, included so the public guide is self-contained.

They are **sanitized**: device serials, SSH keys, host-key fingerprints,
example LAN/MAC addresses and private workspace paths were removed. The
language follows the original.

Relative links inside these archived notes may still point at the original
research tree and are not part of this repository's navigation. The reviewed
English text is [`../README.md`](../README.md); the claim matrix is
[`../EVIDENCE.md`](../EVIDENCE.md). If a raw note differs, the guide wins.
