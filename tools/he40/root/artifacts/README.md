# Put your own extracted original here

`build_tvi_payload.py` expects `artifacts/tvi_original.so`: the **original** `libtvsysinfo.so` pulled from *your own* TV (`/3rd_rw/tvsysinfo/lib/libtvsysinfo.so`).

This repository does not ship vendor libraries. The built payload goes to `tools/pub/libtvsysinfo.so`.
