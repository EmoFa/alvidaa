# Layout reference

`apple-tv-layout-reference.png` — the owner's reference image for the launcher
rework (2026-11-06). It is a screenshot of another TV UI he likes, shared as
*direction, not a spec*: "make it look somewhat like this but no need to copy".

Read it for the composition — where the eye lands, how much of the screen is
quiet, how the bottom edge is used — not for colours, type or exact spacing.
The alvidaa launcher keeps its own dark-glass language.

What the owner asked for in words, which is the actual requirement:

1. Inputs move to a bottom dock.
2. Inputs are detected and given icons (signal state is already in
   `/api/sources`).
3. Scrolling/pressing down reveals the rest — and per his later correction,
   the apps are behind **one** tile that opens the list, not a row of tiles.
