## 2. TV UI: start and page

### 2.1 Start script

`/3rd/opera4x/hisenseUI/start-UI.sh` (ro; called from `/basic/autorun.sh` line 168):

```sh
set -e
cd /3rd/opera4x/hisenseUI
. ./opera_env.sh
export MEMORY_LIMIT=$(( 500*1024*1024 ))
STARTPAGE=/3rd_rw/UI/index.html
# optional: "disk" -> /3rd_rw/UI/index.html; "url" -> http://198.51.100.134/modernTV/UI/hisenseUI/index.html
export LD_PRELOAD="/3rd/opera4x/lib/libcurl.so.4.4.0"
cmd="./bin/hisenseUI"
cmd+=" --hw-gles"
cmd+=" --js-flags=\"--expose-gc\""
cmd+=" --jsplugins-dir=/3rd/UI_jsplugins"
cmd+=" --enable-gpu-rasterization --force-gpu-rasterization"
cmd+=" --force-gpu-mem-available-mb=512 --disable-software-rasterizer"
cmd+=" --disable-web-security"
cmd+=" --http-cache-size=30"
cmd+=" -u ${STARTPAGE}"
# if /3rd_rw/appdata/enable_developer_tools: --remote-debugging-port=9223
exec $cmd
```

- **Page:** `/3rd_rw/UI/index.html` (rw).
- **`--disable-web-security`**: local files/cross-origin allowed; the UI can read `file://`/`/3rd_rw`.
- **`--jsplugins-dir=/3rd/UI_jsplugins`**: TV APIs of the UI.
- **GLES/Mali**: `ins_arm_mali_mod.sh`, `OPERA_EGL_SCREEN_SIZE=1920x1080`; UI CSS uses 1280×720.
- **DevTools 9223** only with `/3rd_rw/appdata/enable_developer_tools` (exists).
- **MEMORY_LIMIT 500 MB**; `--expose-gc`; GPU rasterization.

## 3. Launcher/app data (the actual "where is the UI?")

The UI reads the app/category data via `lib/launcherDataInterface.js` (`ldi.js`) from `/3rd_rw/appdata/launcher/` (bridge root `/3rd_rw/appdata`):

```
/3rd_rw/appdata/launcher/
  preset.txt                 # 26 preinstalled app tiles (cache/list)
  Appinfo.json               # web apps installed by the user (our VidaaRecon)
  deletedPresetApp.txt       # JSON array of hidden tiles
  rememberEditApp.json       # launcher edit state
  settingappinfo.txt         # setting/app info
  data/
    CategoryIndex.xml        # categories (active if serviceUpdate matches the country)
    CategoryList_*.xml
    Category_1001_*.xml      # app tiles (35 KB)
    Category_57_*.xml        # app tiles (35 KB)
    PicInfo.xml              # images/assets
    serviceUpdate.xml        # country/timestamp of the store/category data
    SwitchFeatureList.xml
  res/                       # tile icons (PNG/JPG)
  cache/index.json           # icon cache
  firstNotification.txt, lanCode.txt, NotifySwitchStatus.txt
```

Additionally:

```
/3rd_rw/launcher/            # legacy/asset skin (html/js/css/img/data); data path appdata/launcher
/3rd_rw/UI/data/             # default/fallback launcher data (when store country/timestamp does not match)
/3rd_rw/launcher/data/templateConfig.xml  # template configuration (legacy/UI templates)
/3rd_rw/VIDAAU2Launcher/     # VIDAA U2 tile launcher (alternative skin; activation UNVERIFIED)
```

### 3.1 `ldi.js`: active data source

```js
var mainJSON;
var defaultData = (serviceCountryCode != currentCountryCode) || getAlwaysDefaultDataStatus() || serviceUpdate.timeStamp == 0;
var launcherPath = defaultData ? "UI/data/" : "launcher/data/";
if (defaultData) mainJSON = loadLauncherDefaultData(launcherPath, currentCountryCode);
else mainJSON = readXMLDOM(launcherPath + "CategoryIndex.xml", 1);
...
```

- **Country/language:** `user_db.db` → `tvapi.str.basic.settings.tvset.location = DEU`, `tvapi.i32.language.osd = 16`, brand `his`, region 7.
- **Active path:** `launcher/data/` (`/3rd_rw/appdata/launcher/data`), provided `serviceUpdate.xml` matches the country `DEU` and timestamp ≠ 0; otherwise the `UI/data/` default.
- **Source:** `CategoryIndex.xml`/`CategoryList_*.xml`/`Category_*.xml`/`PicInfo.xml`.
- **`preset.txt`:** is generated from the category/app data + `deletedPresetApp.txt` (`allAppsWriteToFileForUse`); is a **cache**.
- **`deletedPresetApp.txt`:** persistent **hide list** (JSON array of URLs/IDs); the UI/the launcher filters with it.
- **`Appinfo.json`:** user web apps (`pushFavoriteApps`), e.g. our `VidaaRecon`.

- **JS:** `HiBrowser.System.startApp(":am,<app>,:start=<val>")` in the web browser; `Hisense_StartApp(…)` in the UI (signature/behavior `UNVERIFIED`; test in the UI JS/DevTools).
